yuz tekshiruvi, taqiqlangan buyumlar, qurilmaga bog'lash, HMAC imzolangan
so'rovlar. Test markazida topshirilsa (PIN bilan) nazoratning bir qismi
o'chiriladi — u yerda jonli nazoratchilar bor.

## 3. Serverga kirish va joylash

```bash

```

Konteynerlar: `app` (Django+nginx), `worker` (Celery), `beat` (sweep tsikli),
`db` (PostgreSQL), `redis`.

**Joylashning to'g'ri yo'li** — `bash deploy/safe-deploy.sh`. U 6 bosqichni
bajaradi: Python sintaksisi → `tsc` → 276 backend test → migratsiya tekshiruvi →

**Imtihon paytida joylash:** hech kim imtihonda bo'lmasa `up -d --no-deps app
worker`, aks holda gunicorn'ni yumshoq qayta yuklash (SIGHUP) — sessiyalar
uzilmaydi. `beat` konteynerini **har doim** `--force-recreate` bilan yangilang:
u eski image bilan qolib ketib, tuzatilgan xato qaytib kelgan holatlar bo'lgan.

**Testlar:**
```bash
$DC exec -T -w /app/backend app python manage.py test apps.api.tests --noinput
```
Hozir 276 ta test bor, hammasi o'tadi. SQLite ishlamaydi — faqat PostgreSQL.

**Prod bazaga tegmasdan sinash** (tavsiya etiladi):
```bash
cp -r /home/onlinetest/backend /tmp/stage/
$DC run --rm --no-deps -T --entrypoint python -w /app/backend \
   -v /tmp/stage/backend:/app/backend app manage.py test apps.api.tests --noinput
```
